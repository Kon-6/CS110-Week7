# CS110 Week 7 Story Game

## Project Description

For Week 7, I created a three-slide story about Greenward, where I help Sana train new garden operators. The story shows a problem with outdated instructions and how the team works together to improve them.

## Story Slides

Your Arrival in Greenward: I arrive at Greenward and meet Sana, who needs help training new garden operators.

The Outdated Instructions: Sana shows me the old training instructions, and I notice that some steps are confusing.

A New Beginning: I help Sana create clearer instructions so the new operators can understand their tasks.

## Project Features

Three story slides with images and descriptions.

Next and Back navigation.

Restart functionality.

Image loading and error handling.

## Tools Used

Visual Studio Code

C# and XAML

PowerPoint

GitHub

## Testing and Limitations

I completed the story prototype using PowerPoint and edited the WPF project in Visual Studio Code on my MacBook. I could not run the WPF application because it requires Windows.

## What I Learned

This assignment helped me understand how C# and XAML work together. I also learned how to organize images, create a story flow, and use code to move between slides.
